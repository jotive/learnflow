Instalación

Vía recomendada: Docker. Un solo comando levanta todo en orden. No necesitas Python ni Node instalados localmente.

Requisitos previos

HerramientaVersión mínimaVerificar
Docker Engine24+docker --version
Docker Compose v22.20+docker compose version
GNU Make (opcional)4+make --version
Windows: instalar Make con winget install GnuWin32.Make o choco install make. Sin Make, usar los comandos docker compose ... directamente.

Opción B — Backend en local (sin Docker)

Para iterar el backend con el intérprete del host:

1

Crear entorno e instalar dependencias

cd backend
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements-dev.txt

En Linux/macOS usar .venv/bin/python en lugar de .venv/Scripts/python.exe.

2

Levantar la base de datos del contenedor y migrar

docker compose up -d --wait db        # Postgres sano
docker compose run --rm migrate       # migraciones + seed
3

Servir la API

cd backend
.venv/Scripts/python.exe -m uvicorn app.main:app --reload

Pruebas

cd backend
.venv/Scripts/python.exe -m pytest                 # suite + cobertura
.venv/Scripts/python.exe -m pytest -m "not pg"     # excluir Postgres (testcontainers)
.venv/Scripts/python.exe -m flake8 app tests
.venv/Scripts/python.exe -m ruff check app tests
Nota: las pruebas marcadas pg levantan un Postgres real vía testcontainers y requieren Docker. La cobertura se exige en pytest.ini con --cov-fail-under=75 (actual ~97%).
